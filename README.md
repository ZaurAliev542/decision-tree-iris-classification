# decision-tree-iris-classification
Decision Tree classification project using the Iris dataset, including model evaluation, hyperparameter tuning, cross-validation, and feature importance.
# Decision Tree Classification — Iris Dataset

## Overview

This project demonstrates an end-to-end Decision Tree classification workflow using the Iris dataset.

The objective is to predict the species of an Iris flower based on four numerical measurements:

- Sepal length
- Sepal width
- Petal length
- Petal width

## Workflow

- Data loading and exploration
- Feature and target separation
- Train-test split
- Decision Tree classification
- Model evaluation
- Confusion matrix
- Precision, Recall and F1-score
- Decision Tree visualization
- Overfitting analysis
- Hyperparameter analysis
- Cross-validation
- GridSearchCV
- Feature importance

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab

## Model

The project uses `DecisionTreeClassifier` with Gini impurity as the splitting criterion.

## Dataset

The Iris dataset contains measurements of Iris flowers belonging to three species:

- Setosa
- Versicolor
- Virginica

## Key Learning Outcomes

This project demonstrates how a Decision Tree learns rule-based decision boundaries for classification and how model complexity can affect generalization and overfitting.
